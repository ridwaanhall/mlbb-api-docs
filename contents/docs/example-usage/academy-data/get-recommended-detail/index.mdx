---
title: GET Academy Recommended Detail
description: API endpoint to fetch detailed information about a specific recommended Mobile Legends hero guide by ID.
---

## Endpoint

```txt
GET /api/academy/recommended/{id}/
```

## Path Parameters

- **id** (string): Unique identifier of the recommended guide record.  
  Example: `1084006255927552`

## Example Requests

```txt
GET /api/academy/recommended/1084006255927552/
```

## Example Usage

### Python requests

```python {13} showLineNumbers
import requests
import json

def fetch_api(api_url):
    try:
        response = requests.get(api_url)
        response.raise_for_status()
        return response.json()
    except requests.exceptions.RequestException as e:
        print(f"Error: {e}")
        return None

api_url = "https://mlbb-stats.rone.dev/api/academy/recommended/1084006255927552/"
data = fetch_api(api_url)

print(json.dumps(data, indent=4) if data else "No data fetched.")
```
