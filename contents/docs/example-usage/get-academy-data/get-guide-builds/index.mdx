---
title: GET Academy Hero Guide Builds
description: API endpoint to fetch build recommendations for a specific Mobile Legends hero guide by hero ID.
---

## Endpoint

```txt
GET /api/academy/guide/{hero_id}/builds/
```

## Path Parameters

- **hero_id** (integer): Unique identifier of the hero.  
  Example: `132` (Marcel)

## Example Requests

```txt
GET /api/academy/guide/132/builds/
```

## Example Usage

### Python requests

```python {13} showLineNumbers
import requests
import json

def fetch_api(api_url):
    try:
        response = requests.get(api_url)
        response.raise_for_status()
        return response.json()
    except requests.exceptions.RequestException as e:
        print(f"Error: {e}")
        return None

api_url = "https://mlbb-stats.rone.dev/api/academy/guide/132/builds/"
data = fetch_api(api_url)

print(json.dumps(data, indent=4) if data else "No data fetched.")
```
