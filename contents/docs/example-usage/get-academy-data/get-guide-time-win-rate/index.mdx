---
title: GET Academy Hero Guide Time Win Rate
description: API endpoint to fetch time-based win rate statistics for a specific Mobile Legends hero guide by hero ID and lane ID.
---

## Endpoint

```txt
GET /api/academy/guide/{hero_id}/time-win-rate/{lane_id}/
```

## Path Parameters

- **hero_id** (integer): Unique identifier of the hero.  
  Example: `132` (Marcel)

- **lane_id** (integer): Unique identifier of the lane.  
  Example: `3` (Roam)

## Example Requests

```txt
GET /api/academy/guide/132/time-win-rate/3/
```

## Example Usage

### Python requests

```python {13} showLineNumbers
import requests
import json

def fetch_api(api_url):
    try:
        response = requests.get(api_url)
        response.raise_for_status()
        return response.json()
    except requests.exceptions.RequestException as e:
        print(f"Error: {e}")
        return None

api_url = "http://127.0.0.1/api/academy/guide/132/time-win-rate/3/"
data = fetch_api(api_url)

print(json.dumps(data, indent=4) if data else "No data fetched.")
```
