---
title: GET Academy Hero Ratings Subject
description: API endpoint to fetch detailed rating results for a specific Mobile Legends hero ratings subject by subject ID.
---

## Endpoint

```txt
GET /api/academy/hero-ratings/{subject_id}/
```

## Path Parameters

- **subject_id** (integer): Unique identifier of the rating subject.  
  Example: `3275335` (Charismatic Queens)

## Example Requests

```txt
GET /api/academy/hero-ratings/3275335/
```

## Example Usage

### Python requests

```python {13} showLineNumbers
import requests
import json

def fetch_api(api_url):
    try:
        response = requests.get(api_url)
        response.raise_for_status()
        return response.json()
    except requests.exceptions.RequestException as e:
        print(f"Error: {e}")
        return None

api_url = "https://mlbb-stats.rone.dev/api/academy/hero-ratings/3275335/"
data = fetch_api(api_url)

print(json.dumps(data, indent=4) if data else "No data fetched.")
```
