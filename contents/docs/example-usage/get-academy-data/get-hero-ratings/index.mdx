---
title: GET Academy Hero Ratings
description: API endpoint to fetch Mobile Legends hero ratings, rankings, and community votes across different categories (e.g., strongest mage, charismatic queen, jungle king).
---

## Endpoint

```txt
GET /api/academy/hero-ratings/
```

## Path Parameters

None.

## Example Requests

```txt
GET /api/academy/hero-ratings/
```

## Example Usage

### Python requests

```python {13} showLineNumbers
import requests
import json

def fetch_api(api_url):
    try:
        response = requests.get(api_url)
        response.raise_for_status()
        return response.json()
    except requests.exceptions.RequestException as e:
        print(f"Error: {e}")
        return None

api_url = "http://127.0.0.1/api/academy/hero-ratings/"
data = fetch_api(api_url)

print(json.dumps(data, indent=4) if data else "No data fetched.")
```
