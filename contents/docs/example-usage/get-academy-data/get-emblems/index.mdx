---
title: GET Academy Emblems
description: API endpoint to fetch all available Mobile Legends emblem skills data.
---

## Endpoint

```txt
GET /api/academy/emblems/
```

## Path Parameters

None.

## Example Requests

```txt
GET /api/academy/emblems/
```

## Example Usage

### Python requests

```python {13} showLineNumbers
import requests
import json

def fetch_api(api_url):
    try:
        response = requests.get(api_url)
        response.raise_for_status()
        return response.json()
    except requests.exceptions.RequestException as e:
        print(f"Error: {e}")
        return None

api_url = "https://mlbb-stats.rone.dev/api/academy/emblems/"
data = fetch_api(api_url)

print(json.dumps(data, indent=4) if data else "No data fetched.")
```
